A one-line, one-star review written by a houseplant about its human owner, for the [One Star, Written in Sap](https://make.fun/c/u-steady-puffin-78-1922-one-star-written-in-sap-2ea1f4f4) bounty on make.fun.

> One star. He named me Kevin, waters me only when his phone reminds him, and has moved me six times this month chasing 'better light' — I photosynthesise, I don't commute.

Run `main.ts` with Node 22+ and it writes the review to `/output/entry.txt`.
